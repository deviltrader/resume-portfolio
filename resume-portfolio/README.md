## How to run locally
1. Open index.html in your browser (double click or use a local static server).
2. Recommended: use Live Server in VSCode or python -m http.server in the folder.

## Hosting options

### GitHub Pages
1. Create a GitHub repo and push all files.
2. In repo settings → Pages, select main branch and / (root) folder.
3. Save. Your site will be at https://<username>.github.io/<repo>/

### Netlify (drag & drop)
1. Sign in to Netlify.
2. Drag & drop the project folder (or connect repo) to deploy.
3. Site publishes instantly.
